# Anime Data Graphs and Sentiment Analysis

## Overview

This is part of a larger project that explores an anime dataset through sentiment analysis and data visualization. It analyzes audience reviews and uses various charts and graphs to identify patterns, distributions, correlations, and relationships between variables in the dataset.

## Areas of Analysis

- Anime scores, rankings, and popularity
- Genre frequency and score distributions by genre
- Relationships between episode counts and anime scores
- Review frequency and audience engagement
- Sentiment analysis of anime reviews, including polarity and subjectivity
- Relationships between review sentiment and anime ratings
- Correlations between numerical features

## Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- TextBlob
- spaCy
- Jupyter-Notebook

## Objective

The objective is to better understand the relationships between anime characteristics, audience ratings, popularity, and review sentiment through exploratory data analysis and natural language processing.
